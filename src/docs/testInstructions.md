# SalonBook Testing Matrices

### Customer Flow
1. Register account with valid credentials.
2. Sign in and browse catalog.
3. Book appointment and verify slot availability.
4. Cancel pending appointment.
5. Pay for confirmed appointment via Stripe test mode.

### Admin Flow
1. Sign in with administrative credentials.
2. View analytics dashboard.
3. Create/update/deactivate salon treatments.
4. Confirm pending customer bookings.
5. Block/unblock customer access.
